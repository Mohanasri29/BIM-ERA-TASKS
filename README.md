# 📘 BIM ERA Python Training Repository

This repository contains structured Python practice programs completed as part of the **BIM ERA Training Program** .

It is designed to strengthen core programming fundamentals using **conditional statements, logical operators, and real-world problem-solving techniques**.

## 📌 Day 1 – Conditional Logic Basics

Day 1 focuses on building a strong foundation in Python programming using comparison and logical operators such as:
'>, '<', '>=','<=', '==', '!=', along with 'and', 'or', 'not'.

The programs include real-world scenarios such as:
- Employee eligibility verification  
- Student pass/fail analysis  
- Login authentication systems  
- Attendance and driving eligibility checks  
- Basic validation and classification problems  

This module helps learners understand how **decision-making logic (if-else statements)** is applied in everyday software systems.

## 📌 Day 2 – Advanced Conditional Problem Solving

Day 2 builds on the basics by introducing more complex decision-making logic using nested conditions and multiple constraints.

The programs cover real-world applications such as:
- Employee promotion and scholarship eligibility  
- Secure login and authentication systems  
- Flight boarding and bank loan approval systems  
- Smart home security systems  
- Gym membership categorization  
- Weather alerts and e-commerce discount systems  

These exercises strengthen understanding of:
- Multi-condition decision making  
- Real-time logic simulation  
- Automation-based problem solving  

## 🎯 Skills Developed

- Python input/output handling  
- Conditional statements (if, elif, else)  
- Logical and comparison operators  
- Real-world problem modeling  
- Basic decision system design  

## 🚀 Outcome

This project helps in building strong programming logic and prepares learners for:
- Coding assessments  
- Placement technical rounds  
- Real-world application development
